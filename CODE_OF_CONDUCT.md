# Code of Conduct

## Our Pledge

We want this project to be a respectful and practical place for people to discuss, report issues, and contribute improvements.

Everyone participating in this project is expected to be considerate, constructive, and professional.

## Expected Behavior

- Be respectful of different experience levels and backgrounds.
- Focus feedback on the code, design, documentation, or behavior being discussed.
- Explain technical disagreement clearly and calmly.
- Assume good intent, especially when reviewing issues or pull requests.
- Help keep discussions useful for future maintainers and users.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Repeated off-topic comments after being asked to stop.
- Publishing private information without permission.
- Deliberately disruptive behavior in issues, pull requests, or discussions.

## Enforcement

Project maintainers may remove comments, close issues, reject pull requests, or block participants when behavior is harmful to the project community.

Enforcement should be proportional, consistent, and focused on keeping the project healthy.

## Reporting

If you see behavior that violates this code of conduct, contact the project maintainer through GitHub.

Reports will be reviewed with care and handled as privately as practical.
